# Volleyball Stat Calculator - Quick Start Guide

## Szybki Start (Polish)

### Krok 1: Tytuł Meczu
1. Uruchom aplikację
2. Wprowadź tytuł meczu (np. "Drużyna A vs Drużyna B")
3. Kliknij "Next"

### Krok 2: Dodaj Graczy
1. Wprowadź dane gracza:
   - Imię
   - Nazwisko
   - Numer
   - Pozycja (Setter, Outside Hitter, Middle Blocker, Opposite, Libero)
2. Kliknij "Add Player"
3. Powtórz dla wszystkich graczy
4. Kliknij "Next - Track Statistics"

### Krok 3: Śledź Statystyki
1. Wybierz set (1-5) u góry ekranu
2. Wybierz gracza z listy
3. Dla każdej akcji (Attack, Serve, Block, Reception, Dig):
   - Kliknij **+** aby dodać Plus (akcja udana)
   - Kliknij **-** aby dodać Minus (błąd)
   - Kliknij **★** aby dodać Star (wyjątkowa akcja)
4. Powtórz dla wszystkich graczy i setów
5. Kliknij "View Statistics" aby zobaczyć wyniki

### Krok 4: Zobacz Statystyki
- Skuteczność każdego gracza
- Rozbicie na poszczególne akcje
- Kod kolorów:
  - Zielony (≥70%): Świetnie
  - Pomarańczowy (50-69%): Dobrze
  - Czerwony (<50%): Do poprawy

## Quick Start (English)

### Step 1: Match Title
1. Launch the application
2. Enter match title (e.g., "Team A vs Team B")
3. Click "Next"

### Step 2: Add Players
1. Enter player details:
   - First Name
   - Last Name
   - Number
   - Position (Setter, Outside Hitter, Middle Blocker, Opposite, Libero)
2. Click "Add Player"
3. Repeat for all players
4. Click "Next - Track Statistics"

### Step 3: Track Statistics
1. Select set (1-5) at the top of the screen
2. Select player from the list
3. For each action (Attack, Serve, Block, Reception, Dig):
   - Click **+** to add Plus (successful action)
   - Click **-** to add Minus (error)
   - Click **★** to add Star (exceptional action)
4. Repeat for all players and sets
5. Click "View Statistics" to see results

### Step 4: View Statistics
- Effectiveness for each player
- Breakdown by action type
- Color coding:
  - Green (≥70%): Excellent
  - Orange (50-69%): Good
  - Red (<50%): Needs improvement

## Liczniki / Counters

### Plus (+) - Zielony/Green
Akcja udana / Successful action
- Atak punkt / Attack point
- As serwisowy / Ace serve
- Punkt blokiem / Block point
- Idealna przyjęcie / Perfect reception
- Udane wybicie / Successful dig

### Minus (-) - Czerwony/Red
Błąd / Error
- Atak w out/aut / Attack out
- Błąd serwisowy / Service error
- Błąd w bloku / Block error
- Nieudane przyjęcie / Failed reception
- Nieudane wybicie / Failed dig

### Star (★) - Pomarańczowy/Orange
Wyjątkowa akcja / Exceptional action
- Zabójczy atak / Kill shot
- As nie do obrony / Unreturnable ace
- Solo blok / Solo block
- Perfekcyjne przyjęcie pod siatkę / Perfect pass to setter
- Spektakularne wybicie / Spectacular dig

## Skuteczność / Effectiveness

Formuła / Formula:
```
Skuteczność = ((Plus + Star) / Total) × 100%
Effectiveness = ((Plus + Star) / Total) × 100%
```

### Przykłady / Examples

**Przykład 1:**
- Plus: 10
- Minus: 5
- Star: 5
- Skuteczność: (10 + 5) / (10 + 5 + 5) × 100 = 75%

**Przykład 2:**
- Plus: 8
- Minus: 2
- Star: 0
- Skuteczność: (8 + 0) / (8 + 2 + 0) × 100 = 80%

## Wskazówki / Tips

### Po polsku:
1. Śledź statystyki na bieżąco podczas meczu
2. Możesz zmienić set w dowolnym momencie
3. Możesz cofnąć licznik używając przycisków minus przy licznikach
4. Statystyki można zobaczyć w dowolnym momencie
5. Skuteczność jest obliczana automatycznie

### In English:
1. Track statistics in real-time during the match
2. You can change sets at any time
3. You can decrement counters using the minus buttons
4. Statistics can be viewed at any time
5. Effectiveness is calculated automatically
